# NewDen コンセプト

> "Three is the magic number."

考えを「田」の形で整理する、iOS 向けの思考ジャーナルアプリ。アプリ名は **NewDen**（新・田）。

- ステータス: アイデア固めフェーズ（未実装）
- 最終更新: 2026-09-25

---

## 1. コアアイデア

```
┌──────────┬──────────┐
│ 主題      │ 要素①    │
│          │          │
├──────────┼──────────┤
│ 要素②     │ 要素③    │
│          │          │
└──────────┴──────────┘
```

- 1つの「田」は4マス。左上に**主題**、残り3マスに主題を支える**3つの要素**を書く。
- 要素がさらに次の「田」の主題になり、考えが**連鎖**する。
- 連鎖した全体を**一望**できる。

### 位置づけ

- 目標管理アプリではなく、**ジャーナル**に近い。書くことで考えを整理し、後から振り返る。
- 近いものにマンダラチャート（主題1＋要素8）がある。違いは次の点。
  - 3つなら埋められるので、書き始めのハードルが低い。
  - 3つに絞ること自体が、優先順位を考えることになる。
  - 正方形の4分割なので、スマホの縦画面にきれいに収まる。

---

## 2. 用語

| 用語 | 意味 |
|---|---|
| **田** | 4マス（主題1＋要素3）からなる最小単位 |
| **マス** | 田の1区画。テキストを1つ持つ |
| **田んぼ** | 子の関係でつながった田のツリー。最大4階層 |
| **田園** | 田んぼ同士がリンクでつながったネットワーク全体 |
| **型** | 田の書き方のテンプレート（マスの見出しと書き方のヒント） |

---

## 3. ルール

### 3.1 3つとも埋める

- 書きかけの田は**未完**として保存できる（点線などで表示する）。
- **子の田を作れるのは、3つの要素がすべて埋まってから**。

### 3.2 マスの中身

- **テキストのみ**。チェックや進捗などは持たない。
- すべての田に**作成日時を自動で記録**する（タイムライン表示に使う）。

### 3.3 連鎖の方向

- **下に掘る**：要素のマスから子の田を作る（手段・詳細へ）。
- **上に広げる**：主題のマスから親の田を作る。「これは何のため？」「これは何の一部？」と問いかけ、メタな視点に気づくきっかけにする。

### 3.4 階層の上限とブランチ

- 1つの田んぼは**最大4階層**（田は最大 1＋3＋9＋27＝40個）。
- 4階層にする理由（入れ子表示で、iPhone の画面幅 393pt の場合）:

  | 階層 | 田の幅 | 見え方 |
  |---|---|---|
  | 第1層 | 約393pt | 画面いっぱい |
  | 第2層 | 約196pt | 読める |
  | 第3層 | 約98pt | なんとか読める |
  | 第4層 | 約49pt | 文字は読めないが形はわかる |
  | 第5層 | 約25pt | 点にしか見えない |

- 4階層を超える場合は**ブランチ**を切る（新しい田んぼを作ってリンクでつなぐ）。
  - **下に掘る場合**：第4層のマスを主題（左上）にした新しい田んぼを作り、元のマスにはリンクを残す。
  - **上に広げる場合**：4階層ある田んぼの上に親を作ると5階層になるので、親だけの新しい田んぼを作り、そのマスから元の田んぼへリンクする。

## 4. 型

田ごとに型を選ぶ。子の田は親と違う型にできる。

初期バージョンでは下の6種類に固定し、**ユーザー独自の型は作れない**。

| 型 | 左上（主題） | 3つのマス |
|---|---|---|
| 目標 | 目標 | 達成に必要な要素 |
| 出来事 | 今日あったこと | 気づき・学び |
| 感情 | 今の気持ち | その理由 |
| 問い | 問い | 仮説 |
| 迷い | 決めたいこと | 判断の基準 |
| **Three Good Things** | 今日の日付 | 良かったこと3つ |

- Three Good Things は、ポジティブ心理学のセリグマンが提唱した「その日の良かったことを3つ書く」手法。看板になる型の候補。

### 型を変えるとき

- **未完のうちは型を変えられる**（選び間違いを直すため）。型はマスの見出しとヒントにすぎないので、変えても中身は困らない。
- **完成した田の型は固定**。考えが変わったとき（問いに答えが出て目標になった、など）は、**発展**の操作で新しい型の田を作り、元の田とリンクする。「迷っていた」という記録もジャーナルとして残す。

## 5. つながりのモデル

田同士のつながりは、次の2種類だけにする。

| 種類 | 範囲 | 性質 |
|---|---|---|
| **子** | 田んぼの中 | マスがその下の田を持つ関係。4階層まで。循環は禁止 |
| **リンク** | 田んぼの外 | ブランチも参照もリンクとして扱う。**双方向**。循環してもよい |

### 5.1 双方向リンク

- リンクされた側の田に「**この田を参照している場所**」を一覧で表示し、そこから戻れる（バックリンク）。
- 振り返るとき「この考えはどこから来たか」をたどれる。

### 5.2 参照型の共有

- 同じ内容を複数の場所で使うときは、コピーではなく**参照**にする。1か所で直すと、参照しているすべての場所に反映される。
- 子の田を持つマスを参照したときは、参照先では中身を展開せず、**リンクとして表示**する（4階層の上限を守るため）。
- 参照されているマスには、使われている場所の数を**バッジ**で表示する（例：「3か所で使用」）。
- 削除は2つに分ける。
  - **この場所から外す**：参照を外すだけ。
  - **内容そのものを消す**：まだ参照されている場合は警告を出す。

## 6. 表示

表示を切り替えられるようにする。

| 表示 | 用途 |
|---|---|
| **入れ子表示** | アプリの顔。田のマスの中に子の田が入った状態を拡大縮小して、全体を一望する |
| **ツリー表示** | 構造と、田んぼ同士のつながり（田園）を確認する |
| **アウトライン表示** | 文章として読み返す。書き出しにも使う |
| **タイムライン表示** | ジャーナルとして日付順に振り返る |

### 入れ子表示の操作（案）

- 縮小すると、全体が「田」の中に「田」が詰まったフラクタル模様に見える。
- 拡大すると1つの田が画面いっぱいに表示され、そこに集中して書ける。
- ピンチ操作で階層を行き来する。
- 縮小表示で文字が読めない大きさになった深い階層は、**文字を省略**して形だけを表示する。
- 具体的なジェスチャー設計は、HTML モックを作ってから詰める。

## 7. MVP の範囲（案）

1. 田を1つ作って4マスに書き込む（型を選ぶ／未完として保存）。
2. 3つ埋まった要素のマスから子の田を作り、そこへ移動する。
3. パンくずリストかピンチ操作で上の階層に戻る。
4. 入れ子表示で全体を一望する。
5. 端末内に保存する。

後から追加するもの：親の田を作る操作、ブランチ、双方向リンク、参照、ツリー・アウトライン・タイムライン表示、発展、書き出し（画像・テキスト）、iCloud 同期、ウィジェット、iPad と Apple Pencil への対応、AI による要素の提案。
